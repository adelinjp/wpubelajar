Pengertian Git

Git adalah sistem kontrol versi yang dipakai untuk mencatat dan mengelola perubahan kode dari waktu ke waktu.

Fungsi Git

Git memiliki beberapa fungsi, diantaranya:

  • Menyimpan versi kode program
  • Memudahkan kolaborasi antar developer
  • Membantu mengelola proyek perangkat lunak

Keunggulan Git

  • Mencatat riwayat perubahan sehingga versi sebelumnya dapat ditinjau atau dipulihkan.
  • Mendukung kerja kolaboratif tanpa harus saling menimpa perubahan kode.
  • Dapat digunakan secara lokal tanpa koneksi internet.
  • Memungkinkan pengembangan fitur secara terpisah menggunakan branch.
  • Terintegrasi dengan layanan seperti GitHub untuk menyimpan dan berbagi repositori.
